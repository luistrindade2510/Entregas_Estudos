# Projeto 01: Site de portfólio

Site que reúne as 13 entregas de dados deste repositório, com foco em seguros e saúde suplementar.

**Site no ar:** https://luistrindade2510.github.io/Entregas_Estudos/

## Problema de negócio

Como um recrutador entende, em 30 segundos, quem eu sou e o que eu entrego? O site responde isso com uma apresentação curta, a minha trajetória e a lista de projetos com links para o código.

## O que tem no site

- Apresentação e "Sobre mim", com a minha experiência de mais de 5 anos em benefícios (saúde, odontologia e vida).
- Grade com os 13 projetos, cada um com status (concluído ou em andamento) e link para a pasta no GitHub.
- Contatos: GitHub e LinkedIn.
- Layout responsivo, que funciona no computador e no celular.

## Como foi feito

| Etapa | Ferramenta |
|---|---|
| Código (HTML e CSS em um único arquivo) | VS Code, com apoio do Antigravity (IA) |
| Versionamento | Git e GitHub |
| Publicação | GitHub Pages, servindo a pasta `docs/` da branch `main` |

O arquivo do site fica em [`docs/index.html`](../docs/index.html).

## Fluxo de trabalho usado

1. Criei uma **branch** para as mudanças, sem mexer na versão oficial.
2. Fiz **commits** com mensagens claras.
3. Enviei com **push** e abri um **pull request** no GitHub.
4. Li o diff e fiz o **merge** na `main`. O site atualiza sozinho em 1 a 2 minutos.

## Como rodar localmente

1. Clone o repositório:
   ```
   git clone https://github.com/luistrindade2510/Entregas_Estudos.git
   ```
2. Abra o arquivo `docs/index.html` no navegador (dois cliques). Não precisa instalar nada.

## O que aprendi

- O ciclo completo do Git e do GitHub: branch, commit, push, pull request e merge.
- Como publicar um site de graça com GitHub Pages.
- Como usar IA para gerar um rascunho e depois revisar e corrigir o resultado, em vez de aceitar tudo. Por exemplo, ajustei textos que prometiam mais do que os projetos entregam.
